# Descripción del Proyecto
Este trabajo práctico tiene como objetivo aplicar herramientas de gestión colaborativa y control de versiones utilizando Git, GitHub, Jira y Google Colab.
El proyecto consiste en analizar un conjunto de datos de ventas comerciales mediante Python, generando estadísticas básicas y gráficos para interpretar el desempeño de una pequeña empresa.

# Estructura del Proyecto
- /datos → datasets utilizados
- /scripts → código fuente en Python
- /resultados → gráficos y resultados generados

# Escenario Seleccionado
Escenario B – Análisis de Ventas de una Pequeña Empresa
